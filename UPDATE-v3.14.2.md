# Deadlock Cup v3.14.2 — крупнее обычный текст и ники

## Установка поверх v3.14.1
1. В GitHub добавь файл `typography-v3142.css` в корень сайта, рядом с `theme-v314.css`.
2. Замени `index.html` версией из патча — в нём в конце стилей подключён новый файл.
3. Commit changes, дождись публикации на Render, обнови сайт `Ctrl + Shift + R`.

## Что изменилось
- Поля регистрации: подписи 13px, содержимое форм 14px.
- Подсказки и небольшие описания: около 13.5px.
- Данные в админских анкетах: 14px.
- Имена игроков в публичных командах и в админском составе: 15–15.5px, Manrope ExtraBold (800).
- Длинные имена переносятся по словам; строки кнопок остаются отдельными.
- Мобильные размеры скорректированы. Заголовки и логотип не изменялись.

Не запускай SQL и не меняй Supabase, OBS, JS или `config.js`. Этот патч изменяет только CSS и его подключение.
