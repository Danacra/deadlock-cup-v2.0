# Deadlock Cup v3.12 — 11 скрытых изображений, без секции «Организатор»

## Что изменено

- На публичных экранах теперь **11 отдельных изображений** из предоставленных PNG, а не только 5 одинаковых кружков.
- В разделе **«Организатор»** пасхалок нет. Скрипт никогда не добавляет их в `#view-admin`.
- Они распределены по главному баннеру (2), двум боковым блокам одиночной регистрации (2), заголовку командной регистрации (1), баннеру участников (2), команд (2), сетки (2).
- Изображения не накладываются на поля ввода, элементы таблиц или административные кнопки; на узком экране расположение перестраивается в отдельную строку.
- Нажатие показывает **именно выбранное изображение** и счётчик находок `0/11`.
- При отсутствии PNG вместо сломанной картинки появится ясная ошибка с точным именем файла. Настройка цвета #0A0A0A / #B6FF00 сохранена.

## Установка в GitHub поверх v3.11 (или v3.10)

1. Распакуй **патч** и загрузи в корень репозитория `index.html`, `easter-eggs.js` и `easter-eggs.css` с заменой файлов.
2. **Обязательно** загрузи в корень папку `easter-eggs/` с **11 PNG-файлами**. GitHub чувствителен к регистру букв и расположению файлов.
3. Нажми **Commit changes**. Дождись успешного обновления статического сайта на Render.
4. Обнови сайт через **Ctrl+Shift+R**.
5. Для проверки картинок открой в браузере `https://ТВОЙ-САЙТ/easter-eggs/patron.png` и `https://ТВОЙ-САЙТ/easter-eggs/archmother-mask.png`. Если 404 — файлы оказались не там, где нужно.
6. Посмотри на баннер регистрации; затем открой «Участники», «Команды», «Сетка». Для оставшейся пасхалки открой вкладку «Зарегистрировать команду».

> Важно: файл `config.js` в полном ZIP содержит только шаблон. Если сайт уже подключён к Supabase, сохрани свой настроенный `config.js` — не заменяй его. Новый SQL не нужен.
