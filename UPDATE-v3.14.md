# Deadlock Cup v3.14 — TO Orbital Redesign

Обновление дизайна на базе **v3.13 Scattered Secrets**. Регистрация, команды, администраторы, заявки, капитаны, турнирная сетка, пасхалки и Supabase не менялись.

## Изменения

- Вместо старого D// используется предоставленная эмблема **TO**: в шапке, на главном экране, во всех баннерах разделов, карточках команд и футере.
- У эмблемы убран тёмный квадратный фон; изображение используется как прозрачный PNG.
- Основная палитра **#0A0A0A / #B6FF00** сохранена. Золото только внутри самой эмблемы.
- Главный экран: 4 кольца движутся независимо с разными скоростями и направлениями, частицы на орбитах, мягкие градиентные свечения между кольцами, полупрозрачное TO в центре.
- Шапки остальных вкладок: компактная анимированная орбитальная композиция с TO.
- Для обычного текста, ников игроков, форм, подсказок и кнопок используется **Manrope**; большие заголовки сохраняют оригинальный шрифт Valve Occult / старый резервный вариант.
- Плавные входные анимации, подчёркивания навигации, подсветка кнопок и карточек.
- Учитывается `prefers-reduced-motion` — системная настройка отключения анимаций.

## Установка поверх v3.13 — GitHub + Render

1. В патче сохранена структура папок. Загрузите содержимое архива в корень репозитория (не папку-обёртку).
2. **Замените** `index.html`, `tournament.js`, `stable-v3.css` и `overlay.css`.
3. **Добавьте** `theme-v314.css`, `motion-v314.js` и `assets/to-emblem.png`.
4. Убедитесь, что `index.html` подключает последним новый CSS-файл `theme-v314.css`.
5. Сделайте Commit в GitHub, проверьте деплой Render и перезагрузите страницу через Ctrl+Shift+R.

## Manrope и заголовки

На сайте уже подключена онлайн-версия Manrope через Google Fonts, поэтому обычный текст меняется сразу. **Если хотите использовать именно вложенный вами локальный файл**, возьмите `Manrope.ttf` из своего архива `manrope.zip` и самостоятельно загрузите его в GitHub по пути `assets/Manrope.ttf`. Разделы и CSS уже настроены под этот путь.

`ValveOccult-SemiBold.ttf` для заголовков не включён в ZIP, как и раньше. Если вы уже добавили его вручную в корень сайта, сохраняйте этот файл. Если нет — снова загрузите его из вашего исходного файла.

## Не требуется

- Не заменяйте `config.js` в действующем проекте.
- Не запускайте старые SQL-миграции повторно.
- Не меняйте Supabase Edge Functions для применения нового дизайна.

## Тестирование

Код JavaScript проверен на синтаксис, CSS — на структуру, HTML — на корректность необходимых блоков; ZIP проверен на целостность. Полноценное открытие сайта в Chromium в данном окружении блокируется (`ERR_BLOCKED_BY_ADMINISTRATOR`), поэтому проверьте фактическое отображение на опубликованном Render-сайте.
