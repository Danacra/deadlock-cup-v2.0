# Deadlock Cup v3.11 — Visible Easter Eggs

Исправление пасхалок для v3.10. Supabase, команды, анкеты, сетку и OBS не меняет.

## Что было не так

v3.9/v3.10 распределяли 3–5 пасхалок по 6 разделам. Поэтому в цитате «ОДИН ТУРНИР. МНОЖЕСТВО СОПЕРНИКОВ...» знак мог вообще отсутствовать. Кроме того, иконки были прозрачны на 70% и плохо различались на тёмном фоне.

## Исправления

- Каждый из шести декоративных блоков сайта теперь получает **один знак**, в том числе цитата регистрации.
- Все пять разных находок доступны на странице; одна из них может повториться в другом разделе.
- Расположение слегка меняется при перезагрузке, но не перекрывает формы или органы управления.
- Контраст знаков повышен с 30% до 82%. У них есть небольшой обводящий контур.
- Если изображение загружено не в ту папку и не найдено, показывается запасной значок ✧, по которому всё равно можно открыть находку. Но картинки в модальном окне тогда нужно будет восстановить.
- В URL CSS/JS обновлён параметр версии, чтобы браузер не использовал старый кеш.

## Установка поверх v3.10

1. В GitHub замени три файла в корне репозитория: `index.html`, `easter-eggs.js`, `easter-eggs.css`.
2. Проверь, что папка `easter-eggs/` содержит 11 PNG из предыдущей версии. Если отсутствует, добавь её из полного архива v3.11.
3. Commit changes → дождись деплоя Render → обнови через Ctrl + Shift + R.
4. В разделе «Регистрация» справа вверху карточки с цитатой должен появиться символ. Нажми на него — откроется находка.
5. Если символа нет, открой F12 → Network и проверь, что `easter-eggs.js?v=3.11` и `easter-eggs.css?v=3.11` загружаются с HTTP 200/304, а в Console нет ошибок.

**Важно:** если в браузере ширина экрана менее 530px, сам блок цитаты скрыт исходными CSS; другие знаки остаются в баннерах. Не заменяй `config.js` при обновлении.
