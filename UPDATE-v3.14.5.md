# Deadlock Cup v3.14.5 — Select arrow inset

Выпадающие списки (`Регион игры`, `Основной регион команды`, фильтр статусов и другие) получили аккуратную стрелку **с отступом 18 px от правой границы**. Для узких списков составов отступ 12 px. Размеры и работа форм не менялись.

## Установка поверх v3.14.4
1. Загрузите `index.html` и `select-arrow-v3145.css` из патча в **корень** репозитория на GitHub.
2. Сделайте Commit changes.
3. После успешного обновления Render перезагрузите страницу Ctrl+Shift+R.

**Не обновлять** `config.js`, Supabase или SQL. Патч не содержит JavaScript и не изменяет данные пользователей.
