# Deadlock Cup v3.14.3 — Отдельный градиент на каждом кольце

Это визуальный патч для v3.14.2. Теперь кольца не покрываются единым общим свечением. Между каждой парой окружностей есть собственный **замкнутый кольцевой слой** с индивидуальным оттенком и плавным градиентом:

- Центр: тёмный зелёный
- Кольцо 1–2: оливково-лаймовый
- Кольцо 2–3: изумрудный
- Кольцо 3–4: приглушённая латунь

Кольцевые градиенты обрезаны круговыми масками, поэтому не размываются друг в друга. Для маленьких окружностей в баннерах разделов используется тот же подход. Вращение линий, точки, логотип TO и остальные анимации сохранены.

## Установка PATCH

1. В корень GitHub-репозитория добавьте/замените `index.html` из архива.
2. Добавьте в корень новый файл `orbits-v3143.css`.
3. Сохраните изменения через **Commit changes**.
4. Дождитесь завершения публикации Render; нажмите **Ctrl + Shift + R**.

Остальные CSS, JS, `config.js`, Supabase, таблицы и функции не меняйте. Патч рассчитан на v3.14.2; установка вместо другой версии может конфликтовать со стилями.

Если после обновления градиент выглядит прежним, откройте https://ВАШ-ДОМЕН/orbits-v3143.css?v=3.14.3 и убедитесь, что браузер получает CSS (HTTP 200), а не 404.
