# Каталог 3D-моделей Deadlock Cup v3.3

Файл `../models.json` содержит ссылки на GLB-файлы, размещённые на Deadlock Wiki, а не сами модели. Модели не распространяются в этом архиве.

Источники:
- https://deadlock.wiki/Heroes
- https://deadlock.wiki/Category:3D_Models/Heroes

43 из 44 известных игровых героев имеют GLB-ссылку в проверенном списке Wiki. Billy не указан в категории на дату создания версии, поэтому для него предусмотрен переход к странице Wiki без фиктивной модели.

При проблемах с загрузкой по стороннему домену (CORS или блокировка CDN) предусмотрена кнопка «Открыть 3D на Deadlock Wiki». Нельзя гарантировать загрузку встроенного 3D в каждом браузере, пока результат не проверен на опубликованном сайте.

Можно отдельно добавить собственные GLB-файлы с разрешением правообладателя, прописав относительные пути в `models.json`. Не публикуйте сторонние модели без прав на распространение.
