# Модели Deadlock

Для работы 3D-просмотра нужны файлы `.glb`, которые вы вправе использовать и публиковать.

Добавьте модель в эту папку и сопоставьте её с названием героя в `../models.json`:

```json
{
  "Abrams": "./models/Abrams.glb",
  "Yamato": "./models/Yamato.glb"
}
```

Это **примеры**. Таких моделей в архиве нет.

В качестве значения можно использовать и прямую HTTPS-ссылку на `.glb` или `.gltf`, если ресурс допускает внешнее встраивание (CORS). Ссылка на страницу с моделью для `model-viewer` не подходит. Для автономной работы лучше разместить разрешённые к публикации GLB на вашем Render Static Site.

Вы также можете проверить локальный `.glb` через поле загрузки в `viewer.html`, без отправки файла на сервер.
