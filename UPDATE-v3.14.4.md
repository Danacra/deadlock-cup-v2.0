# Deadlock Cup v3.14.4 — Align Form Labels

Исправление только внешнего вида: подписи полей («Игровой ник», «Discord»,
«Регион игры», «Часы в Deadlock» и другие) начинаются на одном уровне с
содержимым полей. Исправление применяется также к карточкам регистрации команды.

## Установка

1. Скопируйте `index.html` и `field-label-align-v3144.css` в корень
   репозитория сайта на GitHub.
2. Выполните Commit changes и дождитесь публикации Render.
3. Обновите страницу через Ctrl + Shift + R.

Другие файлы не заменяйте. `config.js`, Supabase и SQL не меняются.

В CSS используется 14px: 1px рамки + 13px внутреннего отступа ввода.
