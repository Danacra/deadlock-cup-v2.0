# Deadlock Cup v3.4 — без 3D-просмотра

В этой версии полностью убрана функция 3D-просмотра героев. Каталог портретов для выбора 1–3 персонажей, регистрация, команды, сетка, Steam-аватары и OBS не менялись.

## Обновление GitHub

1. Из патча загрузите в корень репозитория `index.html`, `app.js`, `v32.css` и сохраните изменения (Commit changes).
2. Удалите из GitHub `viewer.html`, `viewer.js`, `viewer.css`, `models.json`, папку `models/`, а также старый `START-HERE-v3.3.md` — они больше не нужны.
3. Render обновится автоматически, если включен Auto Deploy. Откройте сайт с Ctrl+Shift+R.

## Если устанавливаете полный архив

1. Перенесите содержимое `deadlock-cup-site/` в корень сайта, включая `index.html`.
2. В `config.js` укажите свой Supabase Project URL и публичный publishable key (только публичный ключ — не секреты).
3. Если обновляете старый репозиторий, удалите перечисленные выше устаревшие файлы 3D.
4. Настройки Supabase и SQL не требуется менять. Текущую базу НЕ удаляйте.
5. Если у вас отдельно подключён локальный шрифт, сохраните ваш `ValveOccult-SemiBold.ttf` в корне проекта (его в архиве нет).

OBS и управление турниром работают как прежде. Изменения касаются только кнопки 3D и файлов просмотрщика.
